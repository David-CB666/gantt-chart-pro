# Contributing to GanttChart Pro

Built for construction professionals who need schedules without MS Project. Contributions that make scheduling workflows smoother are always welcome.

## Ways to Contribute

- **Report bugs** — Open an [Issue](../../issues) with your EDF input file + error details
- **Suggest features** — Start a [Discussion](../../discussions) to talk through ideas
- **Submit PRs** — See below

## Pull Request Process

1. Fork the repo and create a branch (`feat/description` or `fix/description`)
2. Keep changes focused — one feature or fix per PR
3. Test with the included `examples/EDF.xlsx` or your own schedule data
4. Open a PR against `main`

## Code Style

- Python 3.8+
- Type hints where practical
- Comments in English
- Docstrings for public methods

## Adding a Color Scheme

1. Add your scheme to `gantt_styles.json`
2. Add it to `references/color-schemes.md`
3. Submit a PR — include a screenshot of the result

## Questions?

Start a [Discussion](../../discussions). Built by a project manager who actually uses this stuff in the field.
