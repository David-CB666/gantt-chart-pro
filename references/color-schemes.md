## 自定義配色

### 創建新方案

在 `config_v2.json` 的 `schemes` 下添加：

```json
{
  "schemes": {
    "my_brand": {
      "name": "品牌配色",
      "colors": {
        "HEADER_BG": "你的品牌色",
        "HEADER_FG": "FFFFFF",
        "INFO_BG": "F5F5F5",
        "WEEKEND_BG": "E0E0E0",
        "TODAY_LINE": "E74C3C",
        "GRID": "BDC3C7",
        "FONT_COLOR": "2C3E50"
      },
      "stage_colors": {
        "A": "第一階段色",
        "B": "第二階段色",
        "C": "第三階段色"
      }
    }
  }
}
```

### 顏色選擇建議

1. **標題背景** — 深色，高對比度
2. **橫道顏色** — 鮮明但柔和，避免刺眼
3. **周末背景** — 淺灰，不干擾閱讀
4. **今日線** — 醒目顏色（紅/橙）
5. **網格線** — 淺灰，不搶眼

## 問題排查

**Q: 顏色顯示不對？**
A: 檢查 JSON 格式，確保色碼為 6 位十六進制

**Q: 打印後顏色太淺？**
A: 使用 `gray_minimal` 方案，或調深顏色

**Q: 想用其他顏色？**
A: 創建自定義方案，修改 `stage_colors`
